# Privacy Policy for OpenWA WhatsApp Make App

*Last updated: September 2026*

This Privacy Policy explains how data is handled when using the OpenWA WhatsApp integration on Make.com.

## 1. Data Collection & Transmission
- The OpenWA Make application acts solely as a communication bridge between your Make.com account and your own self-hosted OpenWA server instance.
- No message contents, phone numbers, contact data, or API credentials are stored, collected, or sold by the application creators.
- All requests are transmitted directly over HTTP/HTTPS between Make.com servers and your configured OpenWA server endpoint.

## 2. Security
- Your API keys and Session credentials are encrypted and securely stored within Make.com's connection vault according to Make's security standards.
